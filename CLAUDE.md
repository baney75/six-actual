# Six Actual

A three-era combined-arms RTS (WW2 1944–45, Cold War 1989, modern). The player commands through an XO and 8 sub-commanders and can take control of any aircraft. The contract is `docs/BRIEF.md` (v5). Where this file and the brief disagree, the brief's stricter rule wins.

## Donovan's standing overrides (beat the brief)

- **No ElevenLabs, ever** (D020). Speech uses Qwen3-TTS and music uses ACE-Step, both local on Parish1 through `~/.local/bin/parish-media`. SFX are procedural synthesis plus CC0 recordings. Transcription is `tools/asr/transcribe.py` (faster-whisper on the CPU).
- **Claude models everything itself** (D021). Every mesh, material, camo and animation is scripted in Blender 5.2.2. No AI mesh generators, no downloaded models, no CC0 photo textures or HDRIs.

## Session start (every session, in order)

1. Read `docs/STATE.md`, `ROADMAP.md`, the open rows in `REQUIREMENTS.md`, and `tail -40 PROGRESS.md`.
2. Run `scripts/verify.sh --quick` and read the report it names. If it is red, fix that first.
3. Pick the smallest open requirement in the current phase and write the plan into `docs/STATE.md`.

This runs on **Parish1** (RTX 4080 Laptop). Run `~/.local/bin/parish-media status` before any GPU job (Cycles, `--write-movie`, benchmarks). It needs AC power, an idle GPU and no gaming. Never kill a process to free the GPU.

## Work loop

Verifier first, one requirement at a time:

1. Write or extend the check and watch it fail for the right reason.
2. Implement until it passes.
3. Run `scripts/verify.sh --phase N`.
4. Update `REQUIREMENTS.md`, `PROGRESS.md` and `docs/STATE.md`.
5. Commit with the requirement IDs in the message, after Donovan says yes to commits.

## Commands

```bash
scripts/bootstrap.sh                 # idempotent; prints the sudo package line for Donovan
scripts/verify.sh --quick            # G1 G2 G3 G10 G14
scripts/verify.sh --phase 0          # adds G11 G12
scripts/verify.sh --full             # every gate; unbuilt gates fail on purpose

dotnet run --project sim/Headless/SixActual.Headless.csproj -c Release -- --selftest
tools/godot/godot --headless --path game --import

python3 scripts/seed_requirements.py        # refresh REQUIREMENTS.md from BRIEF section F
python3 scripts/assets/seed_registry.py     # refresh assets_src/registry.json from data/units.json
python3 scripts/refs/check_coverage.py      # G14 with its self-test
~/.local/bin/parish-media status            # before ANY GPU job
~/.local/bin/parish-media voice -- --mode design --instruct '<voice>' --text '<line>' --output <abs path>
(cd tools/asr && mise exec -- uv run python transcribe.py <wav>...)
```

`verify.sh` activates mise. When you call `dotnet` or Godot directly, run `eval "$(mise activate bash --shims)"` first, or the .NET SDK is not found.

## Rules that bite

- **verify/ is protected.** A hook blocks edits unless `.claude/verify-unlock` exists (gitignored, one line: the reason and the DECISIONS id). The `commit-msg` git hook rejects a commit that touches `verify/` unless its message starts with `VERIFY:`, `DECISIONS.md` is staged, and nothing outside `verify/` and `DECISIONS.md` is staged. Thresholds only tighten without Donovan's approval.
- **Never** weaken, skip, delete or `#if` out a failing check. Never special-case seeds or detect the harness. Never mock the sim in scenario, soak or integration tests.
- No balance number in code or scenes. Data lives in `data/` and is generated by scripts.
- A modeler never approves its own asset. `art-reviewer` runs in a fresh context.
- Do not describe an image, model or sound you have not opened.
- Placeholders are labeled as placeholders in-game and in `PROGRESS.md`. The 103 roster meshes are placeholders (`registry.json` state `placeholder`).
- Report each item as **prepared**, **verified** (with report path), **built** (with path), or **delivered**.
- Ask Donovan before a commit, push or merge, any paid spend, name sign-off, style-board sign-off, an engine switch, faction sensitivity, a 4th asset rejection, or a requirement waiver.
- Work only inside this repo. `sudo` only through `scripts/bootstrap.sh`, which Donovan runs.

## Agents, skills, hooks

- Subagents in `.claude/agents/`: sim-engineer, godot-engineer, ai-designer, modeler, art-reviewer, ref-hunter, fx-animator, audio-producer, qa-verifier.

- Hooks in `.claude/settings.json`, scripts in `.claude/hooks/`:
  - **Stop:** runs `verify.sh --quick` (skipped if the tree is unchanged since the last green run). It blocks the stop on red unless `docs/STATE.md` has a `KNOWN-RED:` line.
  - **PostToolUse:** `dotnet format` on touched C#, and the data validators on touched `data/` JSON.
  - **PreToolUse:** guards `verify/`.
- Git hooks: `scripts/githooks/` (`core.hooksPath`, set by bootstrap).
