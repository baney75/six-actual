# VFX effect

1. **Ref pack first** (`ref-pack`, class `vfx`). You need 5 or more footage clips with timing notes.
2. Read or add the yield row in `data/vfx/yields.json`, generated by script (fireball radius, smoke height, crater size, light radius, debris count). Nothing is hardcoded in the effect.
3. Build the layers in `game/vfx/`: flash (≤ 2 frames plus a real light), fireball, shock ring, surface-specific ejecta, sparks, smoke column with wind drift, scorch and crater (as sim cover), capped camera shake, and the sound delay (distance ÷ 343 m/s). Surface, type and scale variants are separate effects, not tints.
4. Emit VFX events (spawn, layer start and end) to the event log so G4 timing tests can assert on them.
5. Render the frame strip at frames 0, 1, 2, 4, 8, 15, 30, 60, 120, 300, 900 and 1800, on 3 surfaces, at RTS height and close, into `build/detail_review/vfx/<id>/`. Check `parish-media status` first.
6. Measure GPU cost in the benchmark scene. The G6 barrage of 40 simultaneous 155 mm impacts must stay within budget.
7. Spawn `art-reviewer` with `docs/detail-rubric.md`. You never approve your own effect.

*Event log, yields generator, frame-strip renderer and G15 checker are not built yet (DET-01, Phase 1).*
